# Fuentes para instalación y mantenimiento

Consultadas el 2026-10-07. Documentan productos; no prueban acceso ni una búsqueda en la cuenta de un cliente.

- [OpenAI: skills](https://developers.openai.com/codex/skills): formato común, carga progresiva, descubrimiento local, metadatos y distribución. Aplicación: un skill compartido y referencias por necesidad.
- [OpenAI: AGENTS.md](https://developers.openai.com/codex/guides/agents-md): instrucciones de mantenimiento del repositorio para Codex.
- [OpenAI: Projects en ChatGPT](https://help.openai.com/en/articles/10169521-projects-in-chatgpt): archivos e instrucciones de proyecto. Aplicación: ruta de ChatGPT sin depender de instalación nativa ni acceso a GitHub.
- [GitHub: buenas prácticas de repositorios](https://docs.github.com/en/repositories/creating-and-managing-repositories/best-practices-for-repositories): README claro y expectativas de colaboración. Aplicación: entrada por herramienta, comprobaciones y PR antes de integrar.
- [Anthropic: Claude in Chrome](https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome): distinguir extensión, Cowork y Claude Code de un chat sin control del navegador.
- [LinkedIn: límite de uso comercial](https://www.linkedin.com/help/linkedin/answer/a564226): respetar restricciones de búsqueda y entregar avance.

Las referencias del skill conservan las fuentes de filtros, Boolean y taxonomía. Sus fechas indican las consultas documentadas anteriores; no se ha vuelto a ejecutar aquí toda la interfaz de LinkedIn.
